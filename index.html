About the model

The residual block

y = ReLU(x + F(x)). The shortcut copies the input x. The branch learns F(x). ReLU clips negative sums to zero. Both paths use 8 × 8 × 8 tensors.

The shortcut gives gradients a direct path that helps train deep networks. ReLU can still block it.

Architecture

The stem applies Conv 1→8 and ReLU. Three residual blocks each apply Conv 8→8 → ReLU → Conv 8→8 → add x → ReLU. The classifier flattens the maps into 512 values, computes 10 scores, and applies softmax. Convolutions use 3 × 3 kernels, stride 1, and zero padding 1. This teaching model has 8,714 parameters.

Training

Reading the visualization

The display uses actual model activations. Pick a channel and cell to trace one value. Input, change, sum, and output share a colour scale. Conv 1 scales separately. Motion illustrates the computation.

Limitations

Only the final classifier predicts classes. Accuracy applies to this test split, and softmax probabilities are uncalibrated.
